# qizxopen

Mirror of **Qizx/open 4.1** (XML indexing and searching engine, fully supporting XQuery),
originally published by Axyana Software at http://www.axyana.com/qizxopen/ (no longer available).

Licensed under the Mozilla Public License (MPL).

The tree is laid out as installed files (`usr/...`) and is used as the source
for the [qizxopen AUR package](https://aur.archlinux.org/packages/qizxopen).
