Qizx/open 4.1

Contents of the distribution

docs
Documentation. Contains both PDF and HTML versions of the manual.
bin
Contains launcher scripts for Qizx applications: (.bat extension on Windows). These applications are documented in the User's Guide.
lib
Main library jar: qizx.jar. Qizx Studio: qizxstudio.jar
legal
Licenses and readme for Qizx/open and third-party libraries.
src.zip
Source code of the core engine, applications, API and API utility classes.
